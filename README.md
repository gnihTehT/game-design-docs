## 🃏 爱神塔罗（暂定名）

> 版本 v0.2 | 类型：休闲 / 时间管理 / 剧情恋爱 | 单机小游戏

玩家扮演**爱神**，日常为凡人解读塔罗牌回应祈求——在限定时间内按「过去 → 现在 → 未来」连出牌阵，赚取神力值、经营信众；同时暗中推动一段跨越世界的恋爱，最终让两位主角从世界的两端相遇、相爱。

### 核心玩法

- **日常占卜线**：信徒排队提出请求（指定过去/现在/未来其中一项），玩家在耐心倒计时内按序连线正确的三张牌，赚取神力值。
- **主线恋爱线**：关键信徒占卜成功后进入其视角，通过剧情阅读与 mini game 见证两个陌生人的命运牵引，共 11 关直至终章相遇。
- **资源经营**：神力值购买道具（锤子、火焰、沙漏、神之眼、神谕），信众数即生命值，归零则游戏结束。

## 📂 使用方式

1. 安装 [Obsidian](https://obsidian.md/)（免费）。
2. 克隆本仓库：`git clone https://github.com/gnihTehT/game-design-docs.git`
3. 在 Obsidian 中选择「打开本地仓库作为 Vault」，指向克隆后的文件夹即可。
